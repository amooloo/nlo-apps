NLO Bleach Tray

Makes the bleaching-tray model from a scan, with the gel reservoirs, the Trimlign base and the trim line, and puts it into OrthoFactory as an order. Nothing to pay per case.

Everyday use takes 1 minute

1

Export the patient's scan as an STL from the scanner, with the patient's name in the file name (the scanner does this on its own: Armaan_Shetty_20261015_09-20-31_upper.stl).

2

In File Explorer, drag that file into the folder S:\clinical\3D printing\BleachTray. If you have an upper and a lower, drag both.

3

Wait about a minute. Open OrthoFactory → Production. The patient is listed like any Titan case. Print the model on the Form 4B, thermoform, trim on the Trimlign.

That's it. The file you dragged moves into BleachTray\done when it worked, or into BleachTray\failed with a note explaining what happened when it didn't. The small black window called "NLO Bleach Tray" must be open on the PC that runs the app (Dr. A's PC for now; it starts by itself at sign-in; if it's gone, double-click start_app.bat in the app folder).

If a case needs a look optional

Open the app from any office computer and drop a scan anywhere on the page: it processes on its own and sends the order to OrthoFactory (a green "OrthoFactory order written" line confirms it). See the result in 3D, paint over a tooth the computer missed (hold Shift and drag), re-run; nudge the arch on the base with the Position on the base arrows (Apply rebuilds, Reset goes back to automatic). It runs on Dr. A's PC for now, so that PC has to be on. Clicking Bleach Tray on the NLO apps home page opens it directly.

Open the Bleach Tray app

One-time setup on the PC that runs the app about 10 minutes, one person, once

1

Get the app folder onto the PC: download nlo-bleachtray.zip from Dr. Akhavan (or from the code page → green Code button → Download ZIP), right-click it → Extract All, and put the nlo-bleachtray folder somewhere permanent, for example C:\NLO\nlo-bleachtray.

2

Open that folder and double-click install.bat. A black window walks you through everything:

  • If the PC doesn't have Python 3.13 yet (the free program the app runs on), it downloads the right installer for you. Run it and click Install Now. Then double-click install.bat again. (A newer Python already on the PC is fine; both can stay.)
  • It installs the app's components (a few minutes), finds the Titan folder on its own, learns the Trimlign base from one of your existing Titan exports, and creates the BleachTray drop folder next to the Titan folder.
  • When it asks "Start the watcher automatically every time this PC signs in?", type y. From then on the app starts by itself, watching the drop folder and serving the browser app to the office.
3

Double-click start_app.bat once to start it now. Done — go to Everyday use above.

Good to know

  • Default is the bleaching tray recipe: 0.5 mm reservoirs on the front teeth to the second premolars, trim line following the gum line. Other recipes (3-3, aligner "high line") are available in the browser app.
  • Orders show up in OrthoFactory as Template pieces (TU0A upper / TL0A lower), exactly like a stage-0 Titan export.
  • Processing takes about 30–40 seconds per arch.
  • Something looks wrong on a case? Send Dr. Akhavan the patient name and the files from BleachTray\done\… (or failed\…).
  • Updating: double-click update.bat in the app folder on the PC that runs the app. It fetches the newest version, keeps the settings, and restarts the app.
