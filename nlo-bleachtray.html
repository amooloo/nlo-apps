NLO Bleach Tray

Scan in → bleaching-tray model with reservoirs, Trimlign base and trimline → straight into OrthoFactory. $0 per case.

Open it runs on the lab PC

This one is not a web page — it does real 3D work, so it runs on the lab computer (or any office computer with Python). Start it with python run_app.py in its folder, or use the shortcut on the lab PC desktop once installed.

Open on this computer Code & setup guide

Zero-click

With the watcher running on the lab PC, drop the scanner's STL into S:\clinical\3D printing\BleachTray. About 30 seconds later the finished order is in OrthoFactory's Production list. Upper and lower dropped together become one order. Failures go to failed\ with an error.txt; the browser app below is for checking and fixing a case by hand.

Browser app — check or fix a case

  1. Drop the upper and/or lower scan STL from the scanner.
  2. Name the patient (first, last) and pick the preset — Bleaching tray is the default: 0.5 mm reservoirs on 5-5, trimline scalloped at the gum line.
  3. Process. About 30–45 seconds per arch. Check the 3D preview; if a tooth was missed, fix it with the brush on the Segmentation tab and re-run.
  4. Done. The order appears in OrthoFactory's Production list like any Titan export (the app writes the order folder into S:\clinical\3D printing\Titan). Print the STL on the Form 4B, thermoform, trim on the Trimlign.

Install once

cd nlo-bleachtray
python -m pip install -r requirements.txt
python tools/import_base.py "S:\clinical\3D printing\Titan\<any order folder>\<Patient> - 1 - Maxilla.stl"
python run_watch.py --inbox "S:\clinical\3D printing\BleachTray" --titan "S:\clinical\3D printing\Titan"
python run_app.py      (optional: the browser app)

The third line pulls the Trimlign base out of any existing Titan export; it is not stored in this repository.
